
# NLP Text Cleaning and Tokenization

This project demonstrates basic Natural Language Processing (NLP)
techniques using Python.

## Project Steps

The project performs the following steps:

1. Extract text from Wikipedia using the Wikipedia API.
2. Extract the book "Alice's Adventures in Wonderland" from Project Gutenberg.
3. Display the original text before cleaning.
4. Clean the text using Regular Expressions (`re`).
5. Convert the text to lowercase.
6. Remove punctuation, numbers, and special characters.
7. Remove extra spaces.
8. Perform tokenization using NLTK.
9. Remove selected stopwords.
10. Count the tokens before and after stopword removal.
11. Generate a WordCloud from the Wikipedia text.

## Technologies Used

- Python
- Requests
- Regular Expressions (`re`)
- NLTK
- WordCloud
- Matplotlib
- Wikipedia API
- Project Gutenberg
